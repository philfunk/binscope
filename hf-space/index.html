🔎 binscope

Static binary triage, running entirely in your browser.

This demo runs only binscope's triage stage via Python in WebAssembly (Pyodide). Your file never leaves your browser and is never executed — it is read, not run. The full pipeline (Ghidra, Rizin, capa, angr, Frida, AFL++) runs locally from the GitHub repo.
binscope is for authorized analysis only — malware defense, CTFs, research, interoperability, debugging. MIT licensed · source on GitHub.
